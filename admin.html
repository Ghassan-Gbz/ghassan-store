Important security note

GitHub Pages has no private server-side login. This page uses a GitHub fine-grained access token you enter below to make changes to your repository. It does not save the token in this page or browser storage, but the page is public and its code is visible to everyone. Use a token restricted to this one repository with only Contents: Read and write, never share it, and revoke it when finished. Anyone who gets the token can change your repository. This is not a separate secure admin account.

1 · Connect your repository

Create the token on GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Choose this repository only and grant Contents: Read and write. Do not grant Administration permission.

2 · Add or edit an item

Uploads into downloads/ by default. Keep files reasonably small; GitHub API uploads are not suitable for large files.

3 · Published catalogue

Changes are committed to GitHub. GitHub Pages may take a few minutes to show them.
